# netdisk

## 使用Go+Echo实现的网盘系统（实习项目）

支持文件上传/下载/管理、分享（含文件夹）、回收站的网盘

## 启动

```bash
go run .
```

首次启动会在当前目录生成 `config.yaml`和 `data/` 数据目录。
浏览器打开 <http://localhost:8080/> 即可注册使用。

## 前端（React + Ant Design） 
前端纯AI编写（显然能看出来）

## 功能

- **用户**：注册 / 登录 / 登出、配额统计（默认 1GiB）
- **文件**：上传、新建文件夹、重命名、移动、下载、目录打包 zip
- **分享**：文件与文件夹均可分享，支持有效期、链接复制、取消分享
- **回收站**：软删除、恢复（目录连带子项）、彻底删除、清空回收站
- **分享页**：无需登录的公开查看页，支持文件夹逐层浏览、打包下载
